# SDI-PROJECT3-FULLSTACK

This project addresses a desire to streamline motorcycle PPE and MSF training for Active Duty units under the DAFI 91-207 standards.

----

# ABOUT THE PROJECT

This project demonstrates core full-stack software development concepts—relational database design, Knex.js migrations and seeding, RESTful Express APIs, and containerized deployment with Docker Compose—without unnecessary complexity.

### 🛡️ Core Features

**Rider Profile Selection:** Simple user switching to model different rider profiles and safety records.
**PPE Inventory Management:** Log helmets, jackets, boots, and gloves with brand, purchase date, manufacture date, and crash history.
**Automated Helmet Compliance:** Evaluates helmet manufacture/purchase dates against the 5-year expiration standard and flag-crashed equipment.
**MSF Training Monitor:** Tracks completion dates for BRC/ARC courses and calculates currency intervals.
